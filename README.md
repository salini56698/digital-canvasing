# Digital Canvassing

Making elections engaging for the phone generation.
Animated, swipeable candidate profiles showing declared assets, education, track record, and case status (alleged/pending/convicted), plus a clearly labelled prediction estimate.

## Status
Work in progress (Day 1: project setup)

## Planned tech stack
- Frontend: React + Vite + Framer Motion
- Backend: Python + FastAPI
- Data: ECI affidavits, MyNeta/ADR, PRS

## Disclaimer
All information comes from public sources. Pending cases are allegations, not proof of guilt. Predictions are estimates, not facts.
